# Ночная заправка 3D

Браузерный 3D-симулятор ночной смены для публикации через GamePush на Пикабу Играх. В проекте есть законченный цикл смены: машины, заправка, заказы кофе и еды, пополнение товара, уборка, экономика, репутация, улучшения и шесть типов случайных событий.

**Играть онлайн:** https://zaplavs.github.io/night-gas-station-3d/

## Как устроена смена

- **Трафик.** Машины приезжают издалека по своей полосе трассы, сворачивают на площадку и паркуются носом к магазину. После обслуживания они включают заднюю передачу, отъезжают от колонки, выходят на дорогу и уезжают за горизонт. Мимо заправки изредка проезжает попутный транспорт — с фарами, стопами и фонарями заднего хода.
- **Заправка со шлангом.** Сначала нужно снять пистолет с нужной колонки, затем подойти к лючку автомобиля и заправить его. Пистолет виден в руках, а шланг физически тянется от колонки до игрока и возвращается после обслуживания.
- **Водители.** В салонах легковых автомобилей видны low-poly водители. Кабина подозрительного фургона просматривается через окна, но оба сиденья в ней пусты.
- **Предметы в руках.** Всё, что игрок взял, видно в нижней части экрана: стакан кофе с паром, сэндвич, коробка товара, забытая сумка, швабра и инструменты. Предметы покачиваются при ходьбе, ведут за поворотом камеры и отыгрывают само действие — шваброй возят по полу, отвёрткой крутят.
- **Инвентарь уборщика.** Разлитый кофе убирают шваброй от входа, заклинившую колонку чинят инструментом из ящика у левой стены магазина. Швабру и ключи можно взять и вернуть в любой момент; если руки понадобились под груз, они возвращаются на место сами.
- **Ночное небо.** Над трассой висит луна с ореолом, вокруг — звёздное небо с млечным путём и редкими метеорами. Лунный свет падает именно оттуда, где нарисована луна, а само небо не ловит туман и едет за камерой, поэтому кажется бесконечно далёким.
- **Прыжок.** `Space` на ПК и кнопка «Прыжок» на телефоне. Прыжок работает только по вертикали: перепрыгнуть прилавок, колонку или машину нельзя, зато предмет в руках отстаёт в полёте и проседает при приземлении.
- **Склад на втором этаже.** Запас кофе и сэндвичей лежит наверху: наружная лестница справа от магазина ведёт на площадку, дверь склада открывается сама. Коробку с полки можно взять в любой момент — и по заданию смены, и заранее, пока очереди нет; если запас полон, полка ничего не отдаст. Передумали — коробка возвращается на ту же полку.
- **Итоги смены.** На рассвете смена закрывается: показываются заработок, число обслуженных клиентов, репутация и рекорд заработка за смену. Там же покупаются улучшения (до трёх уровней каждое) и предлагается rewarded-реклама.

## Кампания

30 уровней, шесть глав по пять ночей. Уровень — это данные в `src/content/levels.js`, а не ветка в игровом цикле: название, длительность, цель, плотность потока, терпение клиентов, стартовые запасы, разрешённые события, расписание гарантированных происшествий и окна наплыва.

- **Главы.** «Первые ночи» — только колонка и пистолет. «Магазин» — кофе, еда и склад. «Очередь» — двое клиентов разом. «Железо» — поломки и закрытая на ремонт колонка. «Темнота» — отключения света. «Хаос» — всё выученное одновременно.
- **Цели.** Обслужить N машин, заработать сумму, удержать репутацию, не упустить больше N клиентов. Прогресс виден в панели дел всю смену; на итогах показано, какая именно цель не сошлась и на сколько. Не зачтено — уровень повторяется, деньги и улучшения остаются.
- **Наплывы.** В расписании уровня есть окна, когда машины идут в два-три раза чаще, а очередь становится длиннее. Наплыв объявляется карточкой.
- **Сценарные события.** Часть происшествий гарантирована расписанием: на 21 уровне свет гаснет на 60-й секунде, на 30-м — поломка, два отключения света и три волны машин.
- **Экзамены.** Каждый пятый уровень требует больше, чем любая ночь главы до него, и собирает её механики вместе.
- **Бесконечный режим.** Открывается кнопкой на экране финала кампании: те же правила, цели нет, давление растёт с каждой ночью.

## Запуск

```powershell
npm install
npm run dev
```

Продакшен-билд и проверка:

```powershell
npm test
npm run build
```

`npm test` — быстрая проверка без браузера: ассеты, совпадение разметки с кодом, баланс всех 30 уровней и миграция сохранений. Полный сценарий смены прогоняется в headless Chrome:

```powershell
npm run preview
npm run test:e2e
```

E2E ждёт игру на `http://127.0.0.1:4173` (адрес меняется переменной `TEST_URL`) и работает как с `npm run preview`, так и с `npm run dev -- --port 4173`.

Содержимое папки `dist` можно архивировать в ZIP: `index.html` уже находится в корне билда.

## GamePush

Перед публикацией замените пустые значения `projectId` и `publicToken` в `index.html` на значения из панели GamePush. В панели GamePush создайте строковое поле игрока с поддержкой JSON и ключом `night_station_save`. Игра использует его для облачного прогресса и всегда оставляет локальное сохранение как резервный вариант.

SDK загружается с нескольких официальных адресов. Если SDK или реклама заблокированы, игра продолжает работать без ошибок. Полноэкранная реклама показывается только между сменами, rewarded-реклама — добровольно на экране результатов. За просмотр игрок получает надбавку в 35% от заработка смены (но не меньше ₽50); кнопка подписана точной суммой, и эта сумма не меняется от покупки улучшений.

## Управление

- ПК: клик по игровому окну включает обзор мышью; `WASD`, `Shift`, `Space`, удерживать `E`, `Esc`.
- Телефон/планшет: левый виртуальный стик, свайп по правой части экрана, кнопки «Прыжок» и «Действие».
- Кнопка «Обучение» в правом верхнем углу показывает четыре иллюстрированные подсказки и расположение рабочих зон.

## 3D-ассеты

Все модели созданы скриптом `blender/create_assets.py` через `bpy`, оптимизированы под low-poly и экспортированы в `public/models/*.glb`. Исходная сцена сохранена в `blender/night_station_assets.blend`.

Повторная генерация:

```powershell
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' --background --python blender/create_assets.py
```

## Исходники

- `src/main.js` — сцена, цикл смены, задания и ночные события.
- `src/content/levels.js` — таблица 30 уровней: цели, расписание событий и наплывов.
- `src/content/shifts.js`, `src/content/progress.js` — выбор конфига уровня, бесконечный режим и миграция сохранений.
- `src/traffic.js` — маршруты машин по трассе и площадке, разгон и торможение, фары, стопы и задний ход.
- `src/hands.js` — предметы в руках: отдельная сцена первого плана, которая рисуется поверх мира.
- `src/sky.js` — луна, звёзды, млечный путь и метеоры.
- `src/audio.js`, `src/gamepush.js` — звук и интеграция с GamePush.
