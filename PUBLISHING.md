# Публикация на Пикабу Играх

Инструкция для того, кто выкладывает игру. Правила взяты из документации GamePush —
[размещение в Пикабу Играх](https://docs.gamepush.com/docs/distribution/pikabu/) и
[чек-лист тестирования](https://docs.gamepush.com/tutorials/game-testing-checklist/).

## 1. Перед сборкой

1. Зарегистрируйтесь на [gamepush.com](https://gamepush.com/), создайте проект и возьмите из панели `projectId` и `publicToken`.
2. Впишите их в конец [index.html](index.html):

   ```html
   <script>window.GAMEPUSH_CONFIG = { projectId: '12345', publicToken: 'xxxxx', saveField: 'night_station_save' };</script>
   ```

   `publicToken` публичный: он и так уходит в браузер игрока, прятать его не нужно.
3. В панели GamePush заведите поле игрока: тип **строка с поддержкой JSON**, ключ `night_station_save`. Без него облачный прогресс не сохранится, а игра молча останется на локальном.

## 2. Сборка архива

```bash
npm run release
```

Скрипт собирает `dist/` и кладёт рядом `release/nochnaya-zapravka-3d.zip` — это и есть файл для загрузки. Он проверяет, что `index.html` лежит в корне архива и что в разметке не осталось путей от корня сайта, и предупреждает, если токены не заполнены. Сейчас архив весит около 3 МБ при лимите площадки в 100 МБ.

## 3. Карточка игры

Готовые тексты — можно копировать как есть.

- **Название:** Ночная заправка 3D
- **Короткое описание:** Ночная смена на заправке у трассы: колонки, кофе, склад и странные гости до рассвета.
- **Описание:**

  > Вы заступаете на ночную смену на небольшой заправке у трассы. Машины приезжают за топливом, водители заходят в магазин за кофе и сэндвичами, товар на полках кончается, а оборудование ломается в самый неудобный момент.
  >
  > 30 ночей кампании: сначала только колонка и пистолет, дальше магазин, склад на втором этаже, третий пост, фуры и автобусы, приёмка топлива и отключения света. Ночная выручка остаётся на станции — за неё выкупаются вторая кофемашина, прожекторы над площадкой, скоростные насосы и тележка для коробок.
  >
  > За минуту до конца смены светлеет горизонт и гаснут звёзды. Главное — дотянуть до рассвета.

- **Как играть:** `WASD` — движение, мышь — обзор, `Shift` — бег, `Space` — прыжок, удерживать `E` — действие. На телефоне: левый стик, свайп по правой половине экрана, кнопки «Прыжок» и «Действие». Кнопка «Обучение» в правом верхнем углу открывает девять подсказок.
- **Жанр:** симулятор, тайм-менеджмент
- **Теги:** симулятор, менеджмент, 3D, ночь, атмосферная, казуальная
- **Ориентация:** горизонтальная
- **Возрастное ограничение:** 6+
- **Языки:** русский
- **Внутриигровые покупки:** нет
- **Реклама:** полноэкранная между сменами и rewarded по кнопке на экране итогов

## 4. Отправка на модерацию

1. В кабинете GamePush откройте раздел **Distribution**.
2. Укажите, что внутриигровых покупок нет, и выберите площадку **Пикабу Игры**.
3. Загрузите `release/nochnaya-zapravka-3d.zip`, заполните карточку из раздела выше.
4. Оставьте комментарий для модератора и нажмите «Отправить на модерацию». Заявку обрабатывают примерно за один рабочий день; при отказе в панели приходит список причин.

## Требования площадки и где они закрыты в игре

| Требование | Как закрыто |
| --- | --- |
| Русская локализация | вся игра, обучение и тексты заданий на русском |
| Работает на ПК, телефонах и планшетах без ошибок | `node tests/e2e.mjs` играет смену и на десктопе, и на телефоне |
| Интерфейс тянется под разные экраны | вёрстка на `clamp()`, сцена и HUD перестраиваются под ширину |
| Горизонтальная ориентация | в портрете телефон просят повернуть — экран `#rotate` |
| Звук замолкает при сворачивании страницы | `visibility()` в [src/main.js](src/main.js) останавливает аудиоконтекст |
| Игра встаёт на паузу, когда игрок ушёл со вкладки | там же; вернуться можно кнопкой «Продолжить» |
| Пауза на время рекламного ролика | `bindAdPause` в [src/gamepush.js](src/gamepush.js) — работает независимо от того, есть ли облачный сейв |
| Полноэкранная реклама не чаще раза в 3 минуты | `AD_COOLDOWN` в [src/gamepush.js](src/gamepush.js); отсчёт сдвигает и rewarded |
| Реклама не показывается на старте и внутри смены | полноэкранная — только между сменами, rewarded — по кнопке на итогах |
| Предупреждение перед роликом | `showCountdownOverlay` у полноэкранной |
| Сообщение, если ролик не загрузился | тост «Реклама не загрузилась — надбавка не начислена» |
| Игра работает с блокировщиком рекламы | SDK грузится с нескольких адресов, при отказе смена идёт без рекламы и с локальным прогрессом |
| Нет отдельной регистрации и сбора личных данных | игра ничего не спрашивает |
| Облачные сохранения | поле игрока `night_station_save`, локальная копия как резерв |
| Нет внешних ссылок | проверяется в `npm test` |
| Переключатель звука | кнопка «ЗВУК» в меню паузы, состояние сохраняется |
| Обучение для неочевидного управления | девять иллюстрированных экранов по кнопке «Обучение» |
| Больше 10 минут контента | 30 уровней, около двух часов смен без учёта переигровок |
| Название игры, вкладки и обложки совпадают | проверяется в `npm test` |
| `index.html` в корне архива | `npm run release` |

## Что стоит проверить руками перед отправкой

- [ ] Токены вписаны, архив пересобран `npm run release`.
- [ ] Игра открылась с включённым блокировщиком рекламы и дошла до меню.
- [ ] Прогресс пережил перезаход: пройденная ночь осталась пройденной.
- [ ] На телефоне в горизонтали: стик, свайп, кнопка действия, экраны уровней и станции.
- [ ] Полноэкранная реклама показалась между сменами, а rewarded на итогах начислила надбавку — это видно только с настоящими `projectId` и `publicToken`, до них обе функции просто возвращают «рекламы нет».
